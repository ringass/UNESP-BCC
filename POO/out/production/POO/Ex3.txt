Isso ocorre quando temos em uma mesma classe metodos com o mesmo nome porem com parametros diferentes, ou seja, em tipo e ordem. Isso nao é necessariamente um problema pois o java reconhece isso e os diferencia.

public class MesaEx2{
    String a, b;

    public int calcula(int a, int b){

        return {a + b};
    }

    
    public double calcula(int a, int b){

        return {a + b};

    }

}
